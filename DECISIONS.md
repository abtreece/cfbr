# Decisions

One line each: decision — reason — phase.

- Prior and margin-calibration coefficients use a hybrid fit: leave-one-season-out within tuning seasons 2015–2021, strict expanding window for holdout 2022–2025 and live seasons — keeps headline holdout metrics leak-free while giving early seasons stable weights (user-approved 2026-10-11) — P3/P4
- API usage budgeted against the free tier (1,000 calls/month); every command logs its call count and the backfill is resumable — free tier key; overage can disable the key — P1
- HTTP via `httpx` rather than the `cfbd` client — thin, explicit control over caching and call counting — P0
- Dataframes via polars; storage in DuckDB — spec default — P0
- API key loaded from `CFBD_API_KEY` env var, falling back to a gitignored `.keys` file in the repo root — key was provided in `.keys` — P0
- Games and lines fetched with `seasonType=both` (one call per season each); plays fetched one call per (seasonType, week) — minimizes calls; ~24 calls/season, full 2014–2026 backfill used 297 calls — P1
- Live-season games/lines cached under a week-keyed file (`both_wNN.json`) so a weekly re-run is served from cache, while new weeks fetch fresh data — P1
- Plays for a week are fetched only after every FBS game that week is marked completed — prevents caching a partial week — P1
- `/info` is not counted against the quota (verified: remaining unchanged after the call), so `cfbr quota` uses it freely — P1
- DuckDB table for returning production is `returning_production` (`returning` is a reserved word) — P1
- Team FBS/FCS status per season: FBS if listed by `/teams/fbs` that year, else the classification CFBD attaches in that season's games; anything not FBS (FCS, D-II, unknown) is pooled as FCS — P1
- `/talent` starts in 2015 (no 2014 rows); not needed since 2015 is the first season with a prior — P1
- `/player/returning` has offense-only fields (percentPPA, usage and passing/rushing/receiving splits); no defensive returning production exists, so defensive priors use previous rating, talent and recruiting only — P4
- Play-type mapping (kept as scrimmage): Rush, Rushing Touchdown, Pass Reception, Pass Completion, Pass Incompletion, Passing Touchdown, Pass, Sack, Pass Interception, Pass Interception Return, Interception, Interception Return Touchdown, Fumble, Fumble Recovery (Own), Fumble Recovery (Opponent), Fumble Return Touchdown, Safety. Also required: down 1–4 and distance > 0 — spec's keep list mapped to CFBD labels observed 2014–2026 — P2
- Play-type mapping (dropped): Kickoff, Kickoff Return (Offense), Kickoff Return Touchdown, Punt, Punt Return, Punt Return Touchdown, Blocked Punt, Blocked Punt Touchdown, Field Goal Good, Field Goal Missed, Blocked Field Goal, Blocked Field Goal Touchdown, Missed Field Goal Return (Touchdown), Penalty, Timeout, End Period, End of Half, End of Game, End of Regulation, Two Point Pass/Rush, Defensive 2pt Conversion, Uncategorized, placeholder — special teams, administrative, conversions, and penalty-only rows. ~400 "End Period" rows per season carry a down and PPA (likely the last snap of a quarter mislabeled); dropped per the spec's end-of-period rule (~0.3% of plays) — P2
- CFBD `offenseScore`/`defenseScore` are post-play (a made FG row already shows +3); the margin at the snap is the previous play's score within the game, ordering plays by numeric play id — needed for a correct garbage-time filter — P2
- Success: turnovers (interceptions, opponent fumble recoveries, return TDs) and safeties always fail; offensive TDs always succeed; otherwise the 50/70/100% rule — conventional treatment; yardage on turnover rows is not meaningful — P2
- Plays where both offense and defense are non-FBS are dropped (no FBS information; would only shape the pooled FCS entity against itself) — P2
- 2020 has ~79k scrimmage plays (COVID-shortened season), below the ~120k sanity line; all other seasons 119k–124k. Kept as-is — P2
- Score at the snap skips administrative and kickoff rows (Timeout, End *, Kickoff*, Penalty, Uncategorized, placeholder), whose CFBD scores are often swapped or stale; using every row made scores go down in 54% of 2023 games, using reliable rows only leaves ~0.2% of rows with a score decrease (genuinely corrupt data, accepted) — P2
- Efficiency ridge solved via the normal equations (2·teams + 2 columns; dense solve), intercept and home term effectively unpenalized — exact and ~0.3s per fit on a full season — P3
- O and D are re-centered to mean zero over that season's FBS teams after each fit (intercept absorbs the shift), so 0 = average FBS unit; higher D = better defense, so team net = O + D — P3
- Margin calibration uses one net rating per team for PPA and for success rate (margin = b0·home + b1·Δnet_ppa + b2·Δnet_sr, no intercept, home = 0 at neutral sites), fit by OLS on as-of ratings of games in the training seasons from the hybrid scheme — spec allows this simplification — P3
- Massey baseline: ridge (alpha 10) on margins capped at ±28, same-season games kicked off before the as-of time, no prior — P3
- Ratings "for week w" are those available before week w's first kickoff — P3
- Synthetic recovery test uses a realistic team spread (SD 0.15 PPA/play) and full 13-game schedule; with SD 0.12 and 12 games the best any estimator could manage is r ≈ 0.94, so the 0.95 target tests noise, not the model — P3
- Prior share reported as the ridge shrinkage fraction alpha/(alpha + effective plays), where effective plays are the recency-weighted counts the fit used, averaged over offense/defense and over the PPA and success-rate fits (each with its own alpha). Originally used raw play counts and alpha_ppa only; fixed 2026-10-11 after it misreported week-6 shares — P3/P7
- Process note: the first end-to-end backtest run (results/*-first) used 2015–2025, so its printed aggregate mixed holdout games in before tuning was frozen. No holdout-specific breakdown was viewed, and that run is not used for any tuning decision; all runs until `config/tuned.toml` is frozen use 2015–2021 only — P5
- Prior targets are each season's final ratings from a no-prior, full-season fit (same alpha), not the prior-shrunk ratings — avoids the prior predicting itself — P4
- "Final rating from season s-1" feature uses the same no-prior full-season fit, per component (o_ppa, d_ppa, o_sr, d_sr); one OLS model per component — P4
- 4-year recruiting average weights by class age: incoming 0.15, 1 year back 0.30, 2 years back 0.30, 3 years back 0.25 — true freshmen contribute least, upperclassmen most; missing teams get the season minimum — P4
- Missing returning production or talent is imputed with that season's mean (both published preseason) — P4
- New FBS programs (no prior-season FBS rating) get the mean of the bottom quartile (by O+D) of that season's predicted FBS priors, per component — spec rule — P4
- Pooled FCS entities carry over last season's final rating for the same entity, else the mean of last season's pooled entities — P4
- `prior_k` (k/(k+games) prior weight) not implemented: in the residual-from-prior ridge, alpha already sets prior strength, so k would be a redundant second knob — P4
- Prior-only week-1 MAE (tuning seasons, default config): 2015 15.22, 2016 15.33, 2017 14.76, 2018 15.84, 2019 13.32, 2020 20.03, 2021 16.44 — P4 DoD
- Postseason is split into 7-day prediction slots from the first bowl kickoff (p1, p2, ...), each with its own as-of time, instead of one CFBD postseason "week" — CFP rounds can use earlier bowl results; still strictly point-in-time — P5
- Evaluated games: completed games with at least one FBS team (FBS–FCS included); the line benchmark and ATS are computed on the subset with a closing line — P5
- Closing spread = median of CFBD `spread` across real sportsbooks when any posted a line, else CFBD's `consensus` aggregate, else teamrankings; numberfire (a projection model, not a market) is never used (home perspective; market home margin = −spread). Fixed 2026-10-11: it was previously the median across all providers, mixing numberfire into 2014–2022. Effect: tuning-season line MAE 12.496 → 12.544 (model gap +0.854 → +0.807); holdout unchanged (12.026 → 12.027) — P5
- ATS: model picks the side its predicted margin favors relative to the line; pushes and exact model-line ties are excluded; 95% Wilson interval — P5
- Accepted, unavoidable leakage: CFBD's PPA comes from an expected-points model CFBD fit on its full history. We can't refit it point-in-time; the effect is believed small — P5
- Week-1 predictions use only the prior (no same-season plays before the first kickoff) — P5

- Rating uncertainty (roadmap #3) — evaluation rule fixed 2026-10-11 before building. Step A: exact Gaussian posterior of the existing ridge fit (ratings are a normal-prior MAP, so posterior covariance = σ²(XᵀWX + αI)⁻¹, mapped to points through the calibration); predictive margin SD per game = sqrt(var of rating difference + residual noise²), with residual noise fit on training seasons (hybrid scheme). Step B: NumPyro hierarchical model on the T4 (team effects pooled within conference, prior strength learned, Student-t game noise). Judged on 2015–2021 (primary; walk-forward, all slots) with 2022–2025 as a sanity check: (1) mean log predictive density of the actual margin must beat v1's constant-σ normal, paired 95% CI excluding 0; (2) 50/80/95% interval coverage within ±3 points of nominal; (3) point-prediction MAE not worse than v1 by more than 0.02 (Step B may change the point predictions; Step A doesn't). Step B is also compared with Step A. Passing makes it available for season simulations and confidence-based bet sizing; replacing the published point ratings needs a separate rule — Uncertainty

- Point totals (roadmap #4, part 1) — evaluation rule fixed 2026-10-11 before building. Model, point-in-time and walk-forward like the margin model: each team's points = OLS on (its offense PPA rating − opponent defense PPA rating), the same for success rate, expected offensive plays from a pace model, a home indicator, and the season's league points per game so far (to follow scoring-environment shifts such as the 2023 clock rules). Pace model: ridge on team-game offensive play counts (offense pace + opponent defense pace), shrunk toward half of last season's final pace effects with a 4-game prior. Coefficients fit under the hybrid scheme (LOSO in 2015–2021, expanding otherwise). Total = home points + away points. Baseline: each team's points-for and points-against per game so far, shrunk 50% toward the league average with a 4-game prior. Primary test: 2015–2021 paired total MAE gain over the baseline, 95% CI excluding 0. Sanity: 2022–2025 gain ≥ 0. The gap to the closing total (median across sportsbooks, same source rule as spreads) is reported, not gated. Passing publishes model totals alongside the margin predictions; any totals paper-betting is the paper-bets session's to design with its own rule written in advance — Totals

- Point totals v2 — shadow rule fixed 2026-10-11, before any window game is played. Design, with every setting fixed in advance (none tuned): team points = μ + Off[team] + Def[opponent] + H·home (home +1, away −1, neutral 0), ridge on the season's team-game points so far with recency weights (half-life 3.7 weeks, the margin model's value), Off/Def shrunk toward 0.5 × last season's final (no-prior, unweighted) effects with a 4-game penalty; μ (the scoring environment) and H are unpenalized and estimated from this season's games only (last season's average before 20 games are in). Total = home + away points. Point-in-time, same slots and as-of times as the margin model. Window: 2026 regular-season week 7 onward plus the 2026 postseason (the same window as the roster-prior shadow). Metric: paired total MAE gain over the points-for/against baseline (the totals baseline above), mean with 95% CI. Decision once, after the 2026 postseason: publish v2 totals if the gain is > 0 and its CI lower bound is > −0.10; otherwise drop it. The gap to the closing total is reported each week but not gated. Totals paper-betting, if any, is the paper-bets session's to design under its own rule — Totals
- Matchup (rush/pass) ratings (roadmap #4, part 2) — evaluation rule fixed 2026-10-11 before building. Model: the same ridge as v1 (frozen alpha, half-life, priors), fit separately on rush plays and on pass plays (sacks count as pass; fumble rows, which can't be split, are left out of the split fits), for both PPA and success rate. Each split starts from the team's v1 prior. Matchup expectation for an offense = r·(rush O − opponent rush D) + (1 − r)·(pass O − opponent pass D), where r is the offense's rush share of plays this season so far (shrunk toward the league share with a 100-play prior). Margin = OLS on home, Δ matchup PPA and Δ matchup success rate (home minus away), fit under the hybrid scheme, like v1's calibration. Primary test: 2015–2021 paired margin MAE gain over v1, 95% CI excluding 0. Sanity: 2022–2025 gain ≥ 0. If both pass, it joins shadow tracking on the 2026 week 7+ and postseason window; decision once, after the 2026 postseason: adopt if the window gain is > 0 and its 95% CI lower bound is > −0.10 — Matchup
