Retroactive, not live. These bets were reconstructed after the games, not recorded before kickoff, so they are kept apart from the live record and never count toward its {{ rules.min_sample }}-bet minimum. Each week uses the model's point-in-time prediction (fit only on games played before that week's first kickoff), compared with the opening line and graded at that line; closing-line value (CLV) is measured against the closing line.
How these were built
  • Same rules as the live bets: bet the model's side when it differs from the opening consensus by at least {{ rules.threshold|num }} points, {{ rules.odds }} odds, {{ rules.stake|num }} unit to win, starting from a {{ rules.bankroll|money(false) }} bankroll with every bet a flat {{ rules.unit_value|money(false) }} unit ({{ (rules.unit_value / rules.bankroll)|pct(0) }} of the starting bankroll, not compounding). Break-even win rate {{ breakeven|pct }}.
  • Opening lines come from CFBD: DraftKings, plus offshore Bovada in the consensus. Other US books have no free line history, so the best line is DraftKings' opening number.
  • Two models: the published model (v1 prior), and the roster-prior shadow model, which isn't published. The roster prior was judged on these same weeks, so its numbers here flatter it; its fair test is the shadow comparison from week 7 on.
  • The two models bet many of the same games{% if overlap %} ({{ overlap.both }} in common, {{ overlap.same_side }} on the same side; {{ overlap.v1_only }} v1 only, {{ overlap.roster_only }} roster only){% endif %}, so their records aren't independent.
