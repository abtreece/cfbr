How it works
  • Bet the model's side when its margin is {{ rules.threshold|num }}+ points off the consensus line (the Edge): the median spread across sportsbooks, offshore books included, as on Method. Each bet is recorded once, before kickoff, and never changed.
  • Flat {{ rules.unit_value|money(false) }} bets from a {{ rules.bankroll|money(false) }} bankroll at {{ rules.odds }}: risk {{ unit_risk|money(false) }} to win {{ unit_win|money(false) }}, break-even {{ summary.breakeven|pct }}.
  • Best available is the best line at a book you could bet, at that book's price: since 2026-10-12, the number-and-price pair worth the most against the consensus (a slightly worse number at a better price can win); before that, the best spread. Only {{ rules.pricing_books|join(", ") }} can set the best line{% if "bet365" in rules.pricing_books %} (bet365's lines come from a separate feed used only to price bets, so they never count toward the consensus){% endif %}, so a bet can have none. Every other book, including offshore books ({{ rules.offshore_books|join(", ") }}), counts toward the consensus but never sets the best line. In the Books tooltip, "(pricing only)" marks a line used only to price the bet, never in the consensus.
  • CLV is how many points the recorded line beat the Close: the consensus in the last snapshot before kickoff (at most {{ close_max_age|num(0) }} hours earlier), or CFBD's post-game consensus when none qualifies. It is the first sign of a real edge; win rate is mostly noise at this sample size.
    • {% if show_cents or show_cover %}
  • {% if show_cents %}Edge ¢ prices the edge in cents of fair odds, assuming the model is right. {% endif %}{% if show_cover %}Cover % is a calibrated estimate that found almost no signal; reporting only.{% endif %}
    • {% endif %}
  • Tiers group bets by edge size; none cleared break-even with confidence in the 2015–2021 backtest.
